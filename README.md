# Small_High
## Conventional Commits Specification
| Type       | 含义     | 典型场景              |
| ---------- | ------ | ----------------- |
| `feat`     | 新功能    | 增加云台前馈控制          |
| `fix`      | 修复 Bug | 修复 CAN 丢包         |
| `docs`     | 文档     | 更新 README         |
| `refactor` | 重构     | 调整状态机结构           |
| `perf`     | 性能优化   | 降低视觉处理耗时          |
| `test`     | 测试     | 增加单元测试            |
| `build`    | 构建系统   | 修改 CMake          |
| `ci`       | CI/CD  | 修改 GitHub Actions |
| `chore`    | 其他杂项   | 更新依赖、脚本等          |
| `style`    | 代码格式   | 格式化代码，不改变逻辑       |
| `revert`   | 回滚     | 回滚之前的提交           |
